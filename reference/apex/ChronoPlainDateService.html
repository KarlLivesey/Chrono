ChronoPlainDateService

Released Apex reference · 0.1.0.19 · Subscriber name: skel.ChronoPlainDateService.

Stable public API for PlainDate values. Internal operations own validation and calculations.

Call these static entry points from subscriber Apex. Core operations return new values and validate their source. The package owns the implementation behind these signatures. See Apex usage and arithmetic semantics.
